# Cognia authoring kits

Immutable authoring kits generated by the Cognia Host (`scripts/plugin/authoring-kit.mjs`
in cognia-labs/cognia). Each directory is named by the SHA-256 of its `authoring-kit.json`;
every other file is listed there with its own SHA-256, and `scripts/bootstrap.mjs` on `main`
verifies all of them. Plugin builds pin one kit through `authoring-kit.lock.json`, whose URL
names a commit of this branch, so a published kit never changes. Add a kit in a new commit;
never rewrite or delete one that a pin may still name.
